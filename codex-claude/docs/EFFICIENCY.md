# Efficient factory use

Reuse the versioned dashboard/runtime; never regenerate it for each app. The installer creates only its necessary files and native launchers. Private jobs, reports, logs and usage are created lazily under ignored factory/.local.

Give workers focused objective/contract/diff packets and references to the app map instead of copying full prompts, chats or report history. Reuse the same builder for fixes. Keep independent reviewer inputs independent. Run focused checks while building and the agreed complete acceptance checks on the frozen combined commit. Repeat passed checks only after relevant changes/failures/uncertainty.

Live diagnostics are opt-in, sequential, bounded and deduplicated by runtime/model/environment. Do not launch every role just to check authentication. An uncertain timeout requires reconciliation, not a replacement builder. Preserve real failed/retried usage. Model caching, continuation or shorter byte counts do not prove token or dollar savings.

Approved budgets belong to the plan; optional defaults are in factory/config.json. The owner must enforce dispatch limits using real observations and label partial/unavailable telemetry. The shared bridge does not provide provider-enforced hard spending caps. API-equivalent estimates are distinct from actual subscription charges.
